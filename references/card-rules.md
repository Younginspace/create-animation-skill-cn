# 动态卡片 `card`

适合生日、节日、婚礼/聚会邀请、乔迁、考试加油、官宣、活动提醒。

| 项目 | 规则 |
|---|---|
| 输入 | 0—1张图片；标题；可选副标题和署名 |
| 时长 | 4—10秒 |
| 比例 | 聊天分享默认1:1；朋友圈/视频号素材默认9:16 |
| 主输出 | MP4 |
| 文案 | 标题最多16个汉字；副标题最多30个汉字 |
| 结构 | 进入0.8—1.5秒 → 信息稳定展示2秒以上 → 收束0.8—1.5秒 |
| 动效 | 标题、主体、装饰各自最多一个动作；不同时抢动 |

用户没有给日期、地点、对象或署名时不补写。邀请卡中的时间与地点必须逐字核对。

## 场景化视觉路由

没有图片时，先按文案语义选择视觉系统，不把所有任务都做成“背景 + 中间圆角矩形 + 图标 + 标题”：

| 语义 | 默认视觉系统 | 避免 |
|---|---|---|
| 生日、周岁、新一岁 | 大字排版、蜡烛、火焰、纸屑或彩带；标题是主视觉 | 通用礼物图标放在矩形卡片中央 |
| 聚餐、婚礼、乔迁、活动邀请 | 左对齐信息层级、票券边界、日期/地点轨道或印章语义 | 与生日卡共用居中构图 |
| 考试、冲刺、加油、上岸 | 速度线、进度条、勾画笔迹、斜向动势 | 气球、蜡烛或柔和祝福卡构图 |
| 官宣、提醒、一般祝福 | 非对称海报、色块、印章或轨道图形 | 默认套用中心白色矩形 |

有图片时默认使用全屏照片和信息遮罩，标题按画面留白区排布；不把照片缩进同一个圆角矩形容器。

脚手架只负责提供与语义匹配的可用视觉系统。交付前必须根据实际文案长度、比例和素材主体做一次 composition 个性化调整；纯文字卡不得跳过这一步直接渲染。

验收：主信息停留足够阅读；装饰不盖住日期/地点；最后至少1.1秒稳定，末帧可截图当静态卡片；同一批不同场景不能只有换色差异；删除任一装饰后若表达和层级不受影响，应删除该装饰。
