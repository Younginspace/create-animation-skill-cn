# 照片故事 `photo-story`

适合周末、旅行、宠物成长、亲子记录、生日回忆、家庭纪念。

| 项目 | 规则 |
|---|---|
| 输入 | 3—12张图片；标题可选，可做无标题模式 |
| 时长 | 6—30秒 |
| 比例 | 默认9:16 |
| 主输出 | MP4 |
| 顺序 | 优先沿用用户顺序；需要重排时说明依据并保留事实 |
| 单图停留 | 无文字1.2秒以上；有文字2秒以上 |
| 动效 | 轻微推拉、平移或裁切变化；人物脸部不移出安全区 |

只描述照片可直接支持的事实。未经用户说明，不把相邻照片自动解释成同一天、同一地点或因果关系。无标题时保持 `message.title` 为空，不渲染占位文字。

`check_project.mjs` 会把每个换图点前/中/后三帧写入 `snapshots/transitions/`；逐组查看是否叠影、闪白、顺序错误或人物被遮。

验收：所有照片至少完整出现一次；顺序能复述；标题不虚构；交叉转场任意时点至少有一张照片可见。
