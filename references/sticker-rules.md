# 动态表情包 `sticker`

适合聊天中的即时反应、群聊梗、宠物或人物照片反应、纯文字情绪。

| 项目 | 规则 |
|---|---|
| 输入 | 0—1张主图；1句短文案 |
| 时长 | 2—6秒 |
| 比例 | 默认1:1 |
| 主输出 | 512px 宽、12fps 的本地优化 GIF；需要高清预览时再按需生成MP4 |
| 文案 | 建议2—10个汉字，最多16个汉字 |
| 动效 | 只选一个主动作：弹入、点头、摇摆、放大强调、轻微震动 |
| 循环 | 首尾姿态、位置和背景必须可连续 |

不默认抠图。主体背景复杂时，优先使用完整照片卡片或圆角裁切；只有现有本地抠图能力可用且用户确实需要透明效果时再抠图。

验收：缩到聊天气泡大小仍能读懂；第一秒内进入信息；循环处无明显跳变。
