# 动态表情包 `sticker`

适合聊天中的即时反应、群聊梗、宠物或人物照片反应、纯文字情绪。

| 项目 | 规则 |
|---|---|
| 输入 | 0—1张主图，或1段授权视频；1句短文案 |
| 时长 | 反应型默认1.5—3秒；叙事型可到6秒 |
| 比例 | 默认1:1 |
| 主输出 | 动态表情为512px宽、12fps的本地优化 GIF；明确只要静态图时为512×512 PNG；需要高清预览时再按需生成MP4 |
| 文案 | 建议2—8个汉字，最多16个汉字；超过8字优先拆成提示语和英雄大字 |
| 动效 | 只选一个主动作：弹入、点头、摇摆、放大强调、轻微震动；再加不抢信息的一种微动作 |
| 循环 | 首尾姿态、位置和背景必须可连续 |

## 背景策略

- 有照片时默认让照片全屏铺满，文字直接叠加；不添加渐变画布、装饰圆环、外框或“卡片套卡片”。
- 先用 `cover` 居中裁切。快照显示人物、宠物或关键文字被裁掉时，再改为更合适的 `object-position`。
- 只有安全裁切仍无法保留主体时，才使用模糊延展或极简纯色补边，并在交付说明中说明原因。
- 纯文字表情因 GIF 编码需要可见画布。先按 [creative-direction.md](creative-direction.md) 做语义分层：主句承担第一焦点，提示词、状态符号或结构图形承担第二焦点；背景、中景、前景各有职责。
- “若无必要不要加背景”指不添加与语义无关的照片、纹理或卡片容器，不等于只能使用纯色加一条线。轨道、状态标记、速度色块或低对比大字可以作为结构层，但必须能解释其作用。
- 短句含逗号、冒号或明显的确认/行动关系时，优先拆成提示语和英雄大字；只能改变断句，不能增删原文。
- “没有合成装饰背景”不等于“透明 GIF”。只有渲染和编码链路已经逐帧验证 alpha 时才能承诺透明背景；当前默认不承诺。
- 不默认抠图。只有现有本地抠图能力可用、用户确实需要，且透明交付链路已验证时再抠图。

## 表情语法路由

有图表情不得固定套用“照片 + 底部居中大字 + 慢速推近”。先按用途选择一种语法，再根据快照调整主体裁切和文字锚点：

| 信号 | 默认语法 | 构图与动作 |
|---|---|---|
| 2—4字强反应词，如“绝了”“夯爆了” | `impact-reaction` | 主体特写；大字偏置或斜切；1次快速冲近/回弹，1.5—2秒循环 |
| 5—8字聊天状态或工作回复 | `chat-status` | 提示语 + 英雄大字；避开人脸/动物脸；状态点、盖章或键盘式短动作，2—2.8秒循环 |
| 温和、可爱或关系型表达 | `cute-reaction` | 原图为主体；小型对话气泡或描边字作为语义层；低幅点头/呼吸，2—3秒循环 |
| 用户明确要“梗一点”“土一点”“夸张一点” | `rough-meme` | 紧裁主体；高对比粗描边字；允许有意的短促抖动和低保真感，但不得牺牲可读性 |

- 2—4字优先作为单一英雄词；5—8字可按标点或确认/行动关系拆分。
- 超过8字时，先尝试只改变断句的两级排版；仍拥挤时再建议用户缩短，不擅自改写含义。
- 先查看原图实际像素，标记主体/脸部区域和至少一个安全文字区；自动判断不可靠时以快照人工修正为准。
- 同一批表情保持角色或用色可以一致，但构图、姿势与动效不得只复制模板换字。

## 首帧与循环

- `t=0` 必须已经能读到完整核心语义；首帧可以是稳定态，不得让照片或主句从全透明开始。
- 动画负责加强语气，不承担“把关键信息从无到有”的唯一职责。
- 循环 GIF 不使用整画面淡黑或完全消失来收尾。首尾的主体裁切、文字可见性、比例和旋转必须一致。
- 在120px和240px预览一次：看不清的细线、阴影和副文案应删掉或放大。
- 默认输出聊天发送版；平台收藏/上架版必须另外按目标平台当期规则压尺寸、帧率、色板和体积，不把历史规格写成当前承诺。

验收：缩到聊天气泡大小仍能读懂；首帧语义完整；第一秒内发生一次清楚的语气强化；主次不是只靠颜色区分；至少两种元素采用不同方向、速度或缓动；循环处无明显跳变；背景中的每个新增元素都有表达或可读性理由。

## 视频片段与静态输出

- 视频只截取一个1.5—6秒片段；明确时间不需要 VLM，视觉事件使用本地抽帧联系表定位。具体 brief、长视频和运行边界见 [direct-sticker-contract.md](direct-sticker-contract.md)。
- 视频截 GIF 与静态 PNG 使用 FFmpeg 直接链路，不为基础截取强制加载 HyperFrames CLI 或浏览器。
- 视频画面已有主体运动时不再额外制造全画面缩放或抖动；文字只做低幅呼吸，避免与原动作争夺注意力。
- 静态 PNG 保留“首帧即完整”的同一语法：主体和全部文案一次可读，不用为了看似动态而添加无关速度线、光圈或渐变卡片。
